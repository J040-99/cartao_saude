📋 Como usar

  1. Preencha o nome completo do titular
  2. Indique o número do documento (ID ou passaporte)
  3. Escolha o plano de saúde pretendido
  4. Se pretender alterar os revives restantes, faça-o manualmente
  5. Escolha a data de início (a validade calcula-se automaticamente)
  6. Clique em "Imprimir / Guardar PDF" para gerar o cartão
💡 Dica: Ao mudar a data de início, a validade atualiza-se automaticamente para 30 dias depois. Pode sempre clicar em "Novo cartão" para recomeçar.
